# Heart Disease Prediction Using Machine Learning

## Project Overview

This project predicts the presence or absence of heart disease using Machine Learning classification algorithms.

## Objective

- Clean and preprocess the dataset
- Select relevant features
- Train classification models
- Evaluate model performance
- Compare different Machine Learning models

## Dataset

UCI Heart Disease Dataset.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Machine Learning Models

1. Logistic Regression
2. Decision Tree
3. Random Forest

## Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix

## Project Workflow

1. Data Collection
2. Data Cleaning
3. Feature Selection
4. Train-Test Split
5. Model Training
6. Model Evaluation
7. Model Comparison

## Output

The project generates:

- Confusion matrices
- Model comparison graph
- Accuracy, Precision, Recall and F1-score
- Model comparison results

## Conclusion

This project demonstrates how supervised Machine Learning classification algorithms can be used to analyze the UCI Heart Disease dataset.
